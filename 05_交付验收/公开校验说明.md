# 公开 ZIP 文件校验

请在一个空目录解压正式 Release 的公开 ZIP。从解压根目录读取 [公开 SHA256 清单](../SHA256SUMS.txt)，按行校验列出的文件。清单覆盖除自身外的全部公开文件。[公开文件白名单](公开文件白名单.txt)列出 ZIP 的全部文件，包括该清单本身。公开清单和作者归档清单分别维护。

Windows PowerShell 可在解压根目录运行以下命令。

```powershell
Get-Content -LiteralPath SHA256SUMS.txt -Encoding UTF8 | ForEach-Object {
    $expected, $name = $_ -split '  ', 2
    if ((Get-FileHash -LiteralPath $name -Algorithm SHA256).Hash -ne $expected) {
        throw "SHA256 failure: $name"
    }
}
```
