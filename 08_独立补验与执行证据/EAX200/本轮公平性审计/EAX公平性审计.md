# EAX 与 R14 补验科学审计

本轮从冻结 C/M/K、EAX 和 R14 账本重新计算。EAX 是 2026 年 11 月 21 日北京时间 13:47:30 至 19:21:31 的后续独立运行。原 600 项四项 Holm 家族与后续 EAX 的两项 Holm 家族分别保留。30 秒固定起点诊断单列，原 800 项机制计划仍暂缓。本轮新求解为零。

## EAX 正式交付与统计

200 项唯一派发均有终态，199 条有效路线重新通过独立验环及整数 EUC_2D 计长。首试 `e0316` 保留为证据失败和空分。R13a01 负责 79 项，其中 78 项有效。R13a02 仅对随后 121 项修正事后停止证据判定，这些项均有效。原生求解器、计算资源、计费和时限保持原样。保留 `e0316` 的原始证据，其中准备时间戳为 84.999985801 s、自有 Job 的内核终止调用为 85.000083901 s、停止证明为 85.104539801 s。

## 真实命令、计费和观察器

冻结命令参数为 `1 DATA 100 30`，对应每个进程一个 trial、输出前缀 DATA、种群 100、子代参数 30。重启种子为登记种子加 100,000 乘进程索引。原生源码显示每个新进程在没有输入种群参数时从随机环做 2-opt 初始化，随后进行 EAX 代循环，原生观察器仅发布该进程的严格改进。200 个正式槽的 220 个原生子进程命令、终止、候选消费和 stdout 已检查，199 个有效槽中有 20 个自然完成的子进程，随后启动了新 trial。每个槽最后运行中的子进程按计费限制终止。外部停止本身不等于试验内置条件已经达到，也无法判断全局解的收敛。

原生二进制 SHA256 `db5e3f8d938aeb22d2d7d09a9218256b6e061b2c0149cf94e950bb407cff65a9`。Python 观察器 SHA256 `011f70f5d8b943927eab100c7f9ac0f759bbc9399b93b9abfea3b2938be23b31`。原冻结合约 SHA256 `f86a13532bce63b083728cc196e2746477f70d8fcf7eac4debbc0dbf5eff1e1f`。200 对派发／终态与 800 个正式材料回执得以逐项绑定。

原生代码先发布完成的环文件，再附事件。Python 用十进制解析坐标并转入整数算术，随后对每个唯一候选执行环合法性与精确 EUC_2D 验证及 SHA-256 去重。只有改进当前值的候选再执行快照写入、快照读回哈希和交付写入。199 个有效槽中，217,679 个发布均被消费，其中 210,099 个改善候选有提交事件，7,580 个被验证为未改善，未发现重复消耗路径。原始全批只有一个已发布完整候选没有相应原生时间线条目，在独立核查中按其不可变文件头确认阶段与代数、按 Python 消费记录确认计数，未为它补造时间。有效终态均有完整截止与独立路线证据。

真实全范围 529 至 1,573 与 Gemini 的 579 至 1,555 冲突。C10k.0 为 1,481 至 1,561，C10k.1 为 1,501 至 1,557，C10k.2 为 1,523 至 1,573。最大值除以约 85 秒等于约 18.5 文件／秒，度量为整个名义窗口的平均。这些实例的 Python CPU 秒中位数依次约为 16.51、16.19、16.99，xmc10150 为 10.49。按 12,000 城分组，较小组与较大组的中位数分别为 13.73 和 12.98。CPU 开销随实例变化，文件数量及规模无法单独解释这项变化。

包装器与原生进程都绑定逻辑 CPU0，独立资源采样绑定 CPU1。计费边界是 85 秒请求目标、86 秒前停止证明、88 秒前认证、90 秒前清理。CPU 秒是共享逻辑处理器上的实际处理量，不能直接作等量墙钟扣除或替代未插桩求解的反事实。外层控制器总时长包含约 12 秒的准入和管理阶段。代码里 5 ms 轮询及调度优先级负责采样和及时消费，现有正式记录没有去除观察器的对照来估计速度变化。原生序列化与 Python 处理区间使用不同时间参考，且分别含等待和读写，不能相加为额外净预算损失。

## 现有轨迹能支持的解释

较小组与较大组的首个已发布遗传改进距原生观察器初始化的中位时间分别为 9.99 和 19.25 秒。该事件在种群初始化后发生，但不直接测出何时初始化完毕。发表改进的最大代数在较小组中位 1258.5、较大组中位 888，不能当成完整代数；stdout 在作业被终止时也可能缓冲。176／199 个有效槽在计费第 80 秒或以后仍有改进提交，其中较大组全部 79 个有效槽有这类记录。

这些记录支持同一时间约束下不同实例的实际进展及统计表现存在差异。没有可以单独识别规模、来源、初始化、阶段数、插桩成本和运行时段影响的设计。本轮无法证实“大图未收敛导致路线更长”“小图已收敛导致胜出”或去除包装器会改变多少结果。后续 EAX 是配对的跨时段描述，不证明某个算法在统一交错时段中的公平全局排序。

120 个有效终态原字节与入包终态匹配。实际路线均重新通过独立 EUC_2D 计长。三组来自两张图，各在两条冻结起点上使用同样 20 个续搜种子，顺序按池各 10 对。数据、登记、图 5 源 PNG 及对应 60 对数据的 SHA256 与原运行回执一致。
